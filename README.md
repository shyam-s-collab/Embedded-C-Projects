# Embedded C Projects

This repository contains three Embedded C projects developed to demonstrate core C programming concepts, file handling, data processing, and bit manipulation techniques.

## Address Book

A console-based contact management application that allows users to add, search, edit, delete, and save contact information. The project demonstrates modular programming, structures, and file operations.

### Features

* Add new contacts
* Search contacts
* Edit contact details
* Delete contacts
* Store contacts in files

## MP3 Tag Reader

A utility that reads and displays metadata stored in MP3 files, such as title, artist, album, genre, and year. The project focuses on binary file handling and ID3 tag parsing.

### Features

* View MP3 metadata
* Edit tag information
* Read ID3 tags
* Binary file processing

## Steganography

A data hiding application that embeds secret messages into BMP image files and retrieves them when required. The project demonstrates bit manipulation and secure data hiding techniques.

### Features

* Encode secret data into BMP images
* Decode hidden data from images
* File-based data hiding
* Bit-level manipulation

## Technologies Used

* C Programming
* GCC Compiler
* File Handling
* Structures
* Bit Manipulation
* Makefile
